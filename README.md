A six-word story for the make.fun bounty "Six Words, One Story": the program writes the story to /output/entry.txt.

## Run it

Run `node main.ts` to write the story to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set.
